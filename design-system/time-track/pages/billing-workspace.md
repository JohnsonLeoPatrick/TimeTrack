# Billing and workspace update

This update extends the existing lime brand across the public site and dashboards.

- Use locally hosted Google Sans, normal weight 400–700, for all interface text.
- Use square corners, thin borders, white surfaces, olive accents, and restrained shadows.
- Keep forms in the document flow. Do not trap checkout inside viewport-height panels.
- Use accessible Base UI selects and menus with keyboard support and visible focus.
- Provide 44px minimum controls and layouts that stack on narrow screens.
- Use real pending, error, empty, confirmed, and refunded states. Confirmed payments alone receive success feedback.
- Keep loading feedback tied to real work. Respect reduced motion for transitions and loading indicators.
- Show test payments explicitly. Never present a checkout redirect as verified payment.
- Use database prices, locks, ownership checks, and atomic financial transitions.
- Keep provider credentials on the server. Do not include environment files in the public repository.

The CLI search was unavailable because Python is not installed. The implementation uses the skill's accessibility, responsive layout, forms, and motion checklists.
